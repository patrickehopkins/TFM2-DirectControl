[h2]IMPORTANT NOTES:[/h2]
[h3]MATCH START PRE-SIMULATION[/h3]
The loading screen after the start of a match is noticeably longer. The game requires some pre-simulation time before the battlefield becomes interactive. Wait for the initial synchronization and ready prompt before pressing Ctrl+Home at the start of a game.

[h3]SHORTCUT SETTINGS[/h3]
Some default spectator shortcuts conflict with the controls I've chosen. Please check your personal Shortcut settings, especially 'R' and 'F1'-'F10' in the game's Shortcuts menu. 'Q' and 'A' also overlap replay actions, but Harbinger suppresses those replay actions while it owns the live match. I'll implement customizable mod keybindings later. I promise!
